## 📖 ภาพรวมของโปรเจกต์

**Smart Amulet Verification & Marketplace** เป็นเว็บแอปพลิเคชันที่พัฒนาต่อยอดจาก Classroom Demo โดยผสานเทคโนโลยี **Artificial Intelligence (AI)** และ **Computer Vision** เข้ากับแพลตฟอร์มตลาดกลางสำหรับซื้อขายพระเครื่อง

ระบบช่วยตรวจจับพระเครื่องในภาพ คัดกรองพิมพ์พระ และเปรียบเทียบลักษณะของภาพกับภาพอ้างอิง พร้อมแสดงผลการวิเคราะห์เพื่อประกอบการพิจารณา นอกจากนี้ยังรองรับระบบสมาชิก การลงขายสินค้า การสั่งซื้อ การจัดการออเดอร์ และรายงานสำหรับผู้ดูแลระบบ

ระบบรองรับผู้ใช้งาน 4 ประเภท ได้แก่ **Guest**, **Buyer**, **Seller** และ **Admin** โดยมีสิทธิ์การใช้งานแตกต่างกัน แต่ **ทุกประเภทสามารถดาวน์โหลดประวัติการตรวจพระมาดูได้ รวมถึงผู้ชมที่ไม่ได้เข้าสู่ระบบ**

> **หมายเหตุเกี่ยวกับ AI:** ผลการตรวจสอบเป็นการวิเคราะห์ความคล้ายคลึงของภาพตามโมเดลและอัลกอริทึมที่ใช้ ไม่ใช่ใบรับรองความแท้ของพระเครื่อง และ Confidence Score ไม่ใช่เปอร์เซ็นต์ความแท้

## 👥 ประเภทผู้ใช้งานและสิทธิ์

| ประเภทผู้ใช้งาน | ความสามารถหลัก | ข้อจำกัด |

| **Guest — ผู้ชม** | ชมรายการและรายละเอียดสินค้า ดาวน์โหลดประวัติการตรวจมาดูได้ | ซื้อ ขาย และตรวจพระด้วย AI ไม่ได้ |
| **Buyer — ผู้ซื้อ** | ซื้อสินค้า ดูประวัติการสั่งซื้อของตนเอง และดาวน์โหลดประวัติการตรวจ | ตรวจพระด้วย AI ลงขาย และลบสินค้าไม่ได้ |
| **Seller — ผู้ขาย** | ตรวจพระด้วย AI ซื้อสินค้า ลงขายพระ จัดการออเดอร์ของตนเอง และดาวน์โหลดประวัติการตรวจ | ลบสินค้าไม่ได้ เพื่อเก็บข้อมูลไว้เป็นประวัติการขาย |
| **Admin — ผู้ดูแลระบบ** | ตรวจพระด้วย AI ดาวน์โหลดประวัติการตรวจ ลบบัญชีผู้ใช้ ลบสินค้า ดูภาพรวมออเดอร์ และดาวน์โหลดรายงานยอดขาย | ซื้อสินค้าและลงขายสินค้าไม่ได้ |

## 🌟 ฟีเจอร์หลัก

### 👀 การเข้าชมและดาวน์โหลดประวัติการตรวจ

- เข้าชมรายการและรายละเอียดพระเครื่องได้โดยไม่ต้องเข้าสู่ระบบ
- ผู้ใช้งานทุกประเภทสามารถดาวน์โหลดประวัติการตรวจพระมาดูได้
- Guest และ Buyer ดาวน์โหลดประวัติการตรวจได้ แม้ไม่มีสิทธิ์ตรวจพระด้วย AI
- ผู้ที่ต้องการซื้อหรือขายต้องสมัครสมาชิกและเข้าสู่ระบบด้วยบัญชีที่มีสิทธิ์เหมาะสม

### 🔍 การตรวจพระด้วย AI

เปิดให้ใช้งานสำหรับ **Seller และ Admin**

- **YOLOv8 Object Detection** — ตรวจจับพระเครื่องในภาพ พร้อมแสดงคลาสที่โมเดลทำนายและค่าความมั่นใจ (Confidence Score)
- **Multi-language Display Mapping** — แสดงชื่อพิมพ์พระเป็นภาษาอังกฤษควบคู่กับภาษาไทย เช่น `Somdej Wat Rakang (พระสมเด็จวัดระฆัง)`
- **Advanced Verification** — วิเคราะห์ภาพร่วมกันด้วย 3 แนวทาง:
  - **Contour & Chamfer Distance:** เปรียบเทียบโครงร่างและระยะห่างของขอบภาพ
  - **SSIM:** เปรียบเทียบความคล้ายคลึงเชิงโครงสร้างของภาพ
  - **ORB Feature Matching:** จับคู่จุดเด่นเฉพาะ (Keypoints) ระหว่างภาพ
- **Auto-Overlay & Debug View** — แสดงจุด P* และภาพซ้อนทับ (Overlay) เพื่อช่วยตรวจสอบผลการเปรียบเทียบ
- **Verification History** — จัดเก็บข้อมูลและภาพผลลัพธ์ พร้อมรองรับการดาวน์โหลดประวัติการตรวจ

### 🛒 การซื้อสินค้า

เปิดให้ใช้งานสำหรับ **Buyer และ Seller**

- เลือกชมและตรวจสอบรายละเอียดสินค้าก่อนสั่งซื้อ
- ดาวน์โหลดประวัติการตรวจเพื่อประกอบการพิจารณา
- สั่งซื้อพระเครื่องจากผู้ขาย
- ดูประวัติการสั่งซื้อของตนเอง
- Seller สามารถซื้อสินค้าจากผู้ขายรายอื่นได้

### 🏷️ การขายสินค้าและจัดการออเดอร์

เปิดให้ใช้งานสำหรับ **Seller เท่านั้น**

- ลงขายพระเครื่องพร้อมข้อมูลและภาพสินค้า
- จัดการรายการสินค้าของตนเองตามฟังก์ชันที่ระบบรองรับ
- ตรวจสอบออเดอร์ที่ได้รับ
- จัดการข้อมูลการจัดส่ง
- เก็บข้อมูลสินค้าไว้เป็นประวัติการขาย โดยผู้ขายไม่สามารถลบสินค้าได้

### 🛡️ การดูแลระบบ

เปิดให้ใช้งานสำหรับ **Admin**

- ตรวจพระด้วย AI และดาวน์โหลดประวัติการตรวจ
- จัดการลบบัญชีผู้ใช้
- ลบสินค้าในระบบ
- ตรวจสอบภาพรวมออเดอร์
- ดาวน์โหลดรายงานสรุปยอดขายรายวันเป็นไฟล์ CSV
- ไม่สามารถสั่งซื้อหรือลงขายสินค้า

### 🔐 ระบบสมาชิกและการกำหนดสิทธิ์

- สมัครสมาชิกและเข้าสู่ระบบ
- ยืนยันอีเมลผ่าน **Email Verification**
- ขอรีเซ็ตรหัสผ่านผ่าน **Forgot Password / Reset Password**
- แบ่งสิทธิ์สมาชิกด้วย **Role-Based Access Control (RBAC)**
- รองรับบทบาทสมาชิก **Buyer**, **Seller** และ **Admin**
- รองรับสถานะ **Guest** สำหรับผู้ที่ยังไม่ได้เข้าสู่ระบบ

### ☁️ การจัดเก็บภาพ อีเมล และรายงาน

- จัดเก็บภาพสินค้าและภาพผลลัพธ์การวิเคราะห์บน **Cloudinary**
- เชื่อมต่อ **SMTP Email Service** สำหรับส่งอีเมลยืนยันตัวตนและการแจ้งเตือน
- รองรับการดาวน์โหลดประวัติการตรวจพระสำหรับทุกบทบาท
- ส่งออกรายงานยอดขายในรูปแบบ **CSV** สำหรับ Admin
- กำหนดให้ไฟล์รายงานที่สร้างขึ้นถูกละเว้นจาก Git ผ่าน `.gitignore`

### 🎨 ส่วนติดต่อผู้ใช้

- รองรับ **Light Mode / Dark Mode** พร้อมจดจำการตั้งค่าผู้ใช้
- ออกแบบแบบ **Responsive** สำหรับมือถือและเดสก์ท็อป
- ใช้ **Dynamic Modals** สำหรับแสดงข้อมูลและโต้ตอบกับผู้ใช้
- รองรับการแสดงวันที่และเวลาตาม **Timezone**

## 🧠 แนวทางการตรวจสอบภาพพระเครื่อง

บัญชี **Seller และ Admin** สามารถเริ่มการตรวจสอบภาพพระเครื่องได้ โดยระบบใช้การตรวจจับวัตถุร่วมกับการเปรียบเทียบภาพ

1. **รับภาพพระเครื่อง** — อัปโหลดภาพที่ต้องการตรวจสอบ
2. **ตรวจจับและคัดกรองพิมพ์พระ** — YOLOv8 ทำนายคลาสและแสดงค่าความมั่นใจ
3. **เปรียบเทียบกับภาพอ้างอิง** — วิเคราะห์โครงร่าง โครงสร้างภาพ และจุดเด่นเฉพาะ
4. **แสดงผลการเปรียบเทียบ** — แสดงผลวิเคราะห์ จุด P* และภาพ Overlay
5. **จัดเก็บประวัติ** — บันทึกข้อมูลและภาพผลลัพธ์การตรวจสอบ
6. **ดาวน์โหลดประวัติ** — ผู้ใช้งานทุกบทบาทสามารถดาวน์โหลดประวัติการตรวจที่ระบบเปิดให้ดาวน์โหลดมาดูได้

### องค์ประกอบของการเปรียบเทียบ

| วิธีการ | สิ่งที่วิเคราะห์ | ประโยชน์ |
| :--- | :--- | :--- |
| **Contour & Chamfer Distance** | โครงร่างและระยะห่างระหว่างขอบภาพ | ช่วยตรวจสอบความแตกต่างด้านรูปทรง |
| **SSIM** | ความคล้ายคลึงเชิงโครงสร้างของภาพ | ช่วยเปรียบเทียบรายละเอียดและรูปแบบของภาพ |
| **ORB Feature Matching** | จุดเด่นเฉพาะและการจับคู่ระหว่างภาพ | ช่วยระบุตำแหน่งรายละเอียดที่สอดคล้องกัน |

> สิทธิ์ดาวน์โหลดประวัติการตรวจไม่ได้ให้สิทธิ์เริ่มการตรวจใหม่ โดย Guest และ Buyer ดาวน์โหลดประวัติได้ แต่ตรวจพระด้วย AI ไม่ได้

<a id="setup"></a>

## ⚙️ การติดตั้งและใช้งาน

### 1. เตรียมสิ่งที่จำเป็น

- Python และ pip เวอร์ชันที่รองรับ dependencies ใน `requirements.txt`
- PostgreSQL พร้อมฐานข้อมูลและบัญชีผู้ใช้ที่มีสิทธิ์เหมาะสม
- บัญชี Cloudinary พร้อม API credentials
- บัญชีอีเมลหรือบริการ SMTP
- ไฟล์โมเดลที่ฝึกแล้ว วางไว้ที่ `models/best.pt`

### 2. เปิด Terminal ในโฟลเดอร์โปรเจกต์

ตรวจสอบว่าโฟลเดอร์ปัจจุบันมีไฟล์ `app.py` และ `requirements.txt`

### 3. สร้าง Virtual Environment

```bash
python -m venv .venv
```

เปิดใช้งานบน **Windows PowerShell**:

```powershell
.\.venv\Scripts\Activate.ps1
```

เปิดใช้งานบน **Windows Command Prompt**:

```bat
.venv\Scripts\activate.bat
```

เปิดใช้งานบน **macOS / Linux**:

```bash
source .venv/bin/activate
```

> หากเครื่องใช้คำสั่ง `python3` ให้ใช้ `python3 -m venv .venv` ในขั้นตอนสร้าง environment

### 4. ติดตั้ง Dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. ตั้งค่า Environment Variables

สร้างไฟล์ `.env` ไว้ในโฟลเดอร์เดียวกับ `app.py` แล้วกำหนดค่าตามหัวข้อ [ตัวแปรสภาพแวดล้อม](#environment)

ตรวจสอบว่าฐานข้อมูล PostgreSQL พร้อมใช้งาน และมีไฟล์ `models/best.pt` อยู่ในตำแหน่งที่ถูกต้อง

### 6. เริ่มต้นเซิร์ฟเวอร์

```bash
python app.py
```

ระบบจะเชื่อมต่อฐานข้อมูลและดำเนินการตั้งค่าเริ่มต้นตามที่กำหนดไว้ใน `app.py`

### 7. เปิดใช้งานผ่านเว็บเบราว์เซอร์

[http://localhost:3001](http://localhost:3001)

ผู้ชมสามารถชมสินค้าและดาวน์โหลดประวัติการตรวจได้ ส่วนการตรวจพระ ซื้อสินค้า และขายสินค้า ต้องเข้าสู่ระบบด้วยบัญชีที่มีสิทธิ์ตรงกับการใช้งาน

<a id="environment"></a>

## 🔧 ตัวแปรสภาพแวดล้อม

ตัวอย่างไฟล์ `.env` — เปลี่ยนค่าตัวอย่างทั้งหมดให้เป็นข้อมูลของคุณ:

```dotenv
# PostgreSQL
DATABASE_URL=postgresql://your_db_user:your_db_password@localhost:5432/your_db_name

# Cloudinary
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret

# SMTP Email
SMTP_EMAIL=your_email@example.com
SMTP_PASSWORD=your_smtp_password

# Frontend
FRONTEND_URL=http://localhost:3001
```

| ตัวแปร | รายละเอียด |
| :--- | :--- |
| `DATABASE_URL` | URL เชื่อมต่อ PostgreSQL โดยใช้รูปแบบที่ตรงกับไดรเวอร์ของโปรเจกต์ |
| `CLOUDINARY_CLOUD_NAME` | Cloud name ของบัญชี Cloudinary |
| `CLOUDINARY_API_KEY` | API key สำหรับเชื่อมต่อ Cloudinary |
| `CLOUDINARY_API_SECRET` | API secret สำหรับยืนยันสิทธิ์กับ Cloudinary |
| `SMTP_EMAIL` | อีเมลที่ระบบใช้ส่งข้อความ |
| `SMTP_PASSWORD` | รหัสผ่าน SMTP หรือ App Password ตามผู้ให้บริการ |
| `FRONTEND_URL` | URL หน้าเว็บสำหรับสร้างลิงก์ที่ส่งไปยังผู้ใช้ |

**ข้อควรทราบในการตั้งค่า**

- ไฟล์ `.env` มีข้อมูลลับและต้องถูกละเว้นด้วย `.gitignore`
- หากแชร์ตัวอย่างการตั้งค่า ให้ใช้ `.env.example` ที่มีเฉพาะค่าตัวอย่าง
- การตั้งค่า SMTP host, port และ TLS/SSL ต้องตรงกับผู้ให้บริการและการกำหนดค่าใน `app.py`
- เมื่อเปลี่ยน URL ที่ใช้งานจริง ให้ปรับ `FRONTEND_URL` ให้ตรงกับหน้าเว็บ
- หลังแก้ไข `.env` ให้รีสตาร์ตเซิร์ฟเวอร์เพื่อโหลดค่าใหม่

<a id="usage"></a>

## 🚀 การใช้งานตามบทบาท

### 👀 Guest — ผู้ชม

1. เปิดเว็บไซต์โดยไม่ต้องสมัครสมาชิกหรือเข้าสู่ระบบ
2. เลือกชมรายการและรายละเอียดพระเครื่อง
3. ดาวน์โหลดประวัติการตรวจที่ต้องการมาดู
4. หากต้องการซื้อหรือขาย ให้สมัครสมาชิก ยืนยันอีเมล และเข้าสู่ระบบด้วยบัญชีที่มีสิทธิ์เหมาะสม

**ข้อจำกัด:** ไม่สามารถซื้อสินค้า ลงขาย ตรวจพระด้วย AI หรือลบข้อมูลได้

### 🛒 Buyer — ผู้ซื้อ

1. เข้าสู่ระบบด้วยบัญชี Buyer
2. เลือกชมรายการและรายละเอียดสินค้า
3. ดาวน์โหลดประวัติการตรวจเพื่อประกอบการพิจารณา
4. สั่งซื้อพระเครื่องจากผู้ขาย
5. ดูรายการและประวัติการสั่งซื้อของตนเอง

**ข้อจำกัด:** ไม่สามารถตรวจพระด้วย AI ลงขายสินค้า หรือลบสินค้าได้

### 🏷️ Seller — ผู้ขาย

Seller ใช้งานได้ครบทั้ง **ตรวจพระ ซื้อสินค้า และขายสินค้า** พร้อมดาวน์โหลดประวัติการตรวจได้

#### ตรวจพระด้วย AI

1. อัปโหลดภาพพระเครื่องที่ต้องการตรวจสอบ
2. ดูพิมพ์พระที่โมเดลทำนายและค่า Confidence Score
3. ตรวจสอบผลการเปรียบเทียบ ภาพ Overlay และจุด P*
4. เรียกดูและดาวน์โหลดประวัติการตรวจ

#### ซื้อสินค้า

1. เลือกชมสินค้าที่ลงขายโดยผู้ขายรายอื่น
2. ตรวจสอบรายละเอียดและดาวน์โหลดประวัติการตรวจประกอบการพิจารณา
3. สั่งซื้อสินค้า
4. ดูรายการและประวัติการสั่งซื้อของตนเอง

#### ขายสินค้า

1. ลงขายพระเครื่องพร้อมข้อมูลและภาพสินค้า
2. จัดการรายการสินค้าของตนเองตามฟังก์ชันที่ระบบรองรับ
3. ตรวจสอบออเดอร์ที่ได้รับ
4. จัดการข้อมูลการจัดส่งให้ผู้ซื้อ

**ข้อจำกัด:** Seller ไม่สามารถลบสินค้าได้ เนื่องจากระบบเก็บข้อมูลไว้เป็นประวัติการขาย การลบสินค้าเป็นสิทธิ์ของ Admin เท่านั้น

### 🛡️ Admin — ผู้ดูแลระบบ

1. เข้าสู่ระบบด้วยบัญชี Admin
2. ตรวจพระด้วย AI และดูผลการวิเคราะห์
3. ดาวน์โหลดประวัติการตรวจ
4. จัดการลบบัญชีผู้ใช้และลบสินค้า
5. ตรวจสอบภาพรวมออเดอร์
6. ดาวน์โหลดรายงานสรุปยอดขายรายวันเป็นไฟล์ CSV

**ข้อจำกัด:** Admin ไม่สามารถซื้อสินค้าหรือลงขายสินค้าได้

## 🛠️ การแก้ไขปัญหาเบื้องต้น

| ปัญหา | จุดที่ควรตรวจสอบ |
| :--- | :--- |
| ติดตั้ง dependencies ไม่สำเร็จ | เปิดใช้ virtual environment และตรวจสอบเวอร์ชัน Python กับข้อความผิดพลาดจาก pip |
| เชื่อมต่อฐานข้อมูลไม่ได้ | ตรวจสอบบริการ PostgreSQL, `DATABASE_URL`, ชื่อฐานข้อมูล และสิทธิ์ของบัญชี |
| โหลดโมเดลไม่สำเร็จ | ตรวจสอบไฟล์ `models/best.pt` และความเข้ากันได้กับ dependencies |
| อัปโหลดภาพไม่ได้ | ตรวจสอบ Cloudinary credentials และข้อความผิดพลาดจากเซิร์ฟเวอร์ |
| ไม่ได้รับอีเมล | ตรวจสอบ SMTP credentials, การตั้งค่า host/port และโฟลเดอร์ Spam |
| ลิงก์ยืนยันอีเมลหรือรีเซ็ตรหัสผ่านเปิดไม่ได้ | ตรวจสอบ `FRONTEND_URL` และการเข้าถึง URL จากอุปกรณ์ที่เปิดอีเมล |
| เปิดเว็บที่พอร์ต 3001 ไม่ได้ | ตรวจสอบว่าเซิร์ฟเวอร์ทำงานอยู่ และไม่มีโปรแกรมอื่นใช้พอร์ตเดียวกัน |
| ดาวน์โหลดประวัติการตรวจไม่ได้ | ตรวจสอบว่ารายการมีข้อมูลให้ดาวน์โหลด รวมถึงการเชื่อมต่อและข้อผิดพลาดจากเซิร์ฟเวอร์ ทุกบทบาทมีสิทธิ์ดาวน์โหลด |
| ไม่สามารถซื้อสินค้าได้ | ต้องใช้บัญชี Buyer หรือ Seller |
| ไม่สามารถตรวจพระด้วย AI ได้ | ต้องใช้บัญชี Seller หรือ Admin |
| ไม่สามารถลงขายสินค้าได้ | ต้องใช้บัญชี Seller เท่านั้น |
| ผู้ขายไม่สามารถลบสินค้าได้ | เป็นข้อกำหนดเพื่อเก็บประวัติการขาย การลบสินค้าเป็นสิทธิ์ของ Admin |
| ดาวน์โหลดรายงานยอดขายไม่ได้ | รายงานยอดขายเป็นสิทธิ์ของ Admin ต่างจากประวัติการตรวจที่ทุกบทบาทดาวน์โหลดได้ |

> เมื่อเกิดข้อผิดพลาด ให้ตรวจสอบข้อความใน Terminal ที่รัน `app.py` เพื่อระบุสาเหตุเพิ่มเติม

<a id="limitations"></a>

## 📌 ขอบเขตและข้อจำกัด

- โมเดลรองรับพิมพ์พระตามคลาสและข้อมูลที่ใช้ในการฝึก
- Confidence Score สื่อถึงความมั่นใจของโมเดลในการตรวจจับหรือทำนายคลาส ไม่ใช่ความน่าจะเป็นที่พระเครื่องเป็นของแท้
- คะแนนความคล้ายคลึงขึ้นอยู่กับคุณภาพภาพอ้างอิง แสง มุมถ่าย ความคมชัด และการจัดแนวภาพ
- ภาพที่มีเงาสะท้อน วัตถุบดบัง หรือรายละเอียดไม่ชัดอาจทำให้ผลคลาดเคลื่อน
- ควรใช้ผลวิเคราะห์ร่วมกับการตรวจสอบรายละเอียดและความเห็นจากผู้เชี่ยวชาญ
- ทุกบทบาทดาวน์โหลดประวัติการตรวจได้ แต่การเริ่มตรวจพระด้วย AI ใช้ได้เฉพาะ Seller และ Admin
- ผู้ขายไม่มีสิทธิ์ลบสินค้า เพื่อเก็บข้อมูลไว้เป็นประวัติการขาย ส่วนการลบสินค้าเป็นสิทธิ์ของ Admin
- คำสั่งติดตั้งในเอกสารนี้ใช้สำหรับเริ่มต้นระบบบนเครื่อง การยืนยันความพร้อมสำหรับ Production ต้องอาศัยการทดสอบระบบและสภาพแวดล้อมที่นำไปใช้งานจริง
